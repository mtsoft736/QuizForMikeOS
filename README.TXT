NAME
       quiz - experimental CLI quiz program for MikeOS (16bit real mode)

DESCRIPTION
       quiz is a small experimental assembler program for MikeOS that
       implements a simple command-line quiz.

       It currently supports a single question with basic user input
       handling and answer checking.

       The project serves as a learning experiment focused on low-level
       programming, MikeOS system calls, and control flow in assembly.

       The goal is to gradually extend it into a simple quiz engine with
       multiple questions and additional features.

STATUS
       Experimental prototype. Actively under development.
